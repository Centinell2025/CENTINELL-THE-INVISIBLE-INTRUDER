# Contribution and evidence integrity

Publisher: **Beacon of the Eagle LLC — Centinell Suite Defense**

All contributions must be original or properly licensed, reproducible, and suitable for defensive training. Do not upload real credentials, production logs, personal information, malware binaries, or answers to the public student package.

## Review criteria
1. Every graded answer must be demonstrable from an included artifact.
2. Timestamps must be consistent and use an explicit timezone.
3. Questions must avoid unsupported assumptions about intent or attribution.
4. Synthetic indicators must use reserved examples and documentation IP ranges.
5. Instructor solutions must be kept in a separate private delivery package.
6. Validate the complete lab with an independent playtester before submission.
