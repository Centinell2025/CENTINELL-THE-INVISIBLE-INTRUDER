# Deep-dive DFIR questions (student edition)

**Beacon of the Eagle LLC | Centinell Suite Defense**

1. Which switch port first learned the previously unseen MAC?
2. What DHCP lease associates the suspected rogue address with that MAC?
3. Which artifact independently corroborates the conflicting gateway claim?
4. What was the time interval between new MAC learning and conflicting gateway claim?
5. Which service account was flagged for an unexpected source?
6. Which authentication event occurred shortly after that flag?
7. When was the service-account session revoked?
8. What action was taken on the switch port, and when?
9. Which IoT control must be verified before firmware restoration?
10. Which file-server recovery validation remains pending?
11. What evidence would distinguish authorized maintenance from malicious IoT changes?
12. Why do these logs not prove that the adversary used Kali Linux?
13. Which source artifacts support a UTC chronology, and which lack explicit year information?
14. What evidence would be needed to conclude data exfiltration rather than ordinary telemetry?
15. Design a prioritized recovery sequence for WS-17, FS-02, and IOT-GW-01 with explicit safety gates.

Every answer must cite source rows; open-ended questions are intended for instructor rubric review rather than exact-string grading.
