# Advanced investigation questions — student edition

**Beacon of the Eagle LLC | Centinell Suite Defense**

Use exact artifact paths and log rows. Do not guess beyond the evidence.

1. What was the baseline gateway MAC before the conflicting advertisement?
2. What MAC claimed the same gateway IP, and on which switch interface was it observed?
3. At what UTC time did WS-17 observe the gateway MAC change?
4. Which DNS query received an unexpected response, and what resolver supplied it?
5. What was the unexpected response IP?
6. Which IoT gateway configuration key changed, and what were its previous and new values?
7. Which IoT device experienced intermittent telemetry?
8. Which Windows host had a new service flagged for review?
9. Which evidence supports a poisoning hypothesis and what additional evidence would distinguish malicious poisoning from misconfiguration?
10. Which restoration steps must precede reconnecting the IoT gateway to production?
11. Why would a factory reset or antivirus-only response be insufficient as a universal recovery strategy?
12. What evidence would be necessary before attributing the intrusion to a Kali Linux system?

Instructor answers and grading proofs must be created and kept outside this student-facing repository.
