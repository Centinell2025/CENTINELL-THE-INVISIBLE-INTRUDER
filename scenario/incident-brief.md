# Incident brief — The Invisible Intruder

On 2026-09-18 a fictional company's security team notices a series of unusual administrator logins and outbound connections. Endpoint malware scanning detects nothing. Analysts receive synthetic Windows authentication logs, Linux SSH logs, network firewall records, and DNS observations.

**Assignment:** reconstruct how the intrusion moved from workstation `WS-17` through `FS-02` to `LINUX-JUMP-01`, identify anomalies, and recommend containment that minimizes business disruption.

All timestamps are UTC. All data is synthetic. Do not assume that every administrator action is malicious: corroborate claims using multiple artifacts.
